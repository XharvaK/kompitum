# Security

This is a private fork with no releases, so tell the Owner directly about a security bug. Keep exploit details out of commits, notes and issues.

A bug that is also in upstream's code belongs with upstream too, through GitHub's [Report a vulnerability](https://github.com/herdrdev/herdr-core/security/advisories/new). That report goes outside this repository, so it is the Owner's to send.

See [Security and trust](docs/security.md) for the runtime's access and trust model.
